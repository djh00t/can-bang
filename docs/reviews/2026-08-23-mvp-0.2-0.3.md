## What worked

- Contract-first: full protocol reference mapped before writing code.
- In-process event bus + SQLite feed instead of a message queue.
- Demos as executable assertions — they caught real bugs (helper misuse).
- Docker smoke incl. restart persistence as an evidence tier.
- Stable dependency pins after the advisor's pre-release picks.

## What failed (root cause → fix)

1. Blank web UI (root page rendered nothing): `index.html` referenced
   `/dist/app.js`; the compiler emitted `main.js`. Never verified asset names
   against build output.
2. `/new` returned 500: edit-key share inserted before the doc row (FK).
3. Demo flakes: `expect_409` leaked its description into curl args (no
   `shift`); `req()` mis-parsed header-only calls; `since=latest` skipped the
   events we meant to assert.
4. Coverage dropped below the gate the moment new branches shipped without
   tests (browser/agent negotiation).
5. Docker build failed: `pnpm-lock.yaml` not copied into the context.
6. `curl` became policy-blocked mid-session; lost time before switching to
   `node fetch`.
7. SMTP was planned and then dropped — speculative scope.
